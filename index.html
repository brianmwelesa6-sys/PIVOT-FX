ABOUT PIVOT FX

Alpha Vantage forex data

The server fetches Alpha Vantage FX daily and weekly candles; hourly candles and the 4-hour aggregation use Alpha Vantage's premium intraday endpoint. Your API key stays on the local server in the ignored .env file and is never sent to the browser.

Quotes may be delayed or subject to provider plan limits. Technical indicators describe the returned candles; they are not forecasts or financial advice.
